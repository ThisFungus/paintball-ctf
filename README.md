# Paintball CTF

Top-down paintball capture-the-flag in the browser (Slovak UI). 2 v 2 or 3 v 3, bots fill empty slots.

**Play:** https://thisfungus.github.io/paintball-ctf/

Online play needs no account: click **Online → Vytvoriť zápas**, copy the invite and send it to a friend.
The match runs in the host's browser; messages go through free public MQTT relays (broker.emqx.io, broker.hivemq.com).
